检测方式

仅启用的目标由 Web 后台每 60 秒检查存活与就绪、每 300 秒执行一次真实推理检查。关闭后不再发起后续健康请求，已经开始的检查会自然结束；已保存的日志仍可查看。

页面每 30 秒仅读取最近 3 小时的历史，时间均为北京时间。刷新记录、切换监测目标均不会主动触发 GPU 推理。无记录或超过 180 秒未采样时，不能据此认定服务健康。

可用率为成功探测轮数占全部观测轮数的比例，忙碌样本单列且计入分母；P95 / P50 统计 Ready 耗时，包含网络时间。这些是探测样本指标，不代表业务 SLA。

启用 Colab 监测只使用已有连接，不会创建或续租实例，也不能阻止平台回收资源。本地电脑与 Colab 的日志、开关和到期信息各自独立。
